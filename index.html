USDK

UltraSonic Development Kit

The ultimate framework for Games and Apps.

Its programming language is UltraSonic Language, using the .ultrasonic extension.

USDK is part of the UltraSonic Technologies ecosystem.

main.ultrasonic UltraSonic 
-- "/" is used for namespaces instead of "::", ":" or "."

package com/sonic5/main.ultrasonic
    -> system/define_project("game")

import USDK/prelude.ultrasonic

~+ (fn) game[USDK/game/main]()

    if !USDK/window/init then
        print("Window not initialized")
    end

    [USDK/Components/USWindow] -> W

    usdkNewWindow(
        W,
        "USDK Window",
        1280,
        720
    )

    W/shape as shape =
        usdkShape("Triangle")

    shape/color =
        usdkGradient(
            from shape/top = rgb(
                0,
                0,
                0
            ).to(
                shape/bottom_start =
                    rgb(1, 1, 1)
            )
        )

end
